# Limitless Control: getting started

Limitless Control lets you play, record and mix using an Xbox Adaptive Controller, your own
accessibility switches, or any game controller.

## What you need

- A Mac (macOS 11 or newer), or a Windows 10 or 11 PC
- An Xbox Adaptive Controller, or any Xbox-style controller
- Logic Pro, Pro Tools or Ableton Live. It also works in any other app.

## 1. Connect the controller

- **USB:** plug the controller into the computer with a USB-C cable.
- **Bluetooth:** turn the controller on, then hold its small pair button until the Xbox light
  flashes quickly. On the computer, open **Bluetooth settings** and choose **Xbox Adaptive Controller**.

## 2. Install

**Mac**
1. Open the `.dmg` file. Choose **Apple silicon** for newer Macs (M1 and later) or **Intel** for
   older ones. To check, open the Apple menu and choose About This Mac.
2. Drag **Limitless Control** into **Applications**.
3. Open it from Applications. The first time, macOS may say it can't check the app. If so, open
   **System Settings > Privacy & Security**, scroll down, and choose **Open Anyway**.
4. Your web browser opens the Limitless Control page. If it shows **One step left on Mac**,
   choose **Open Accessibility settings** and switch on **Limitless Control**. Then quit and
   reopen the app. This lets it send commands to Logic and Pro Tools.
5. If the controller doesn't respond while Logic or Pro Tools is in front, also switch on
   Limitless Control in **Privacy & Security > Input Monitoring**.

**Windows**
1. Run the `Setup.exe` file. If Windows shows **Windows protected your PC**, choose
   **More info**, then **Run anyway**.
2. Tick **Start Limitless Control when I sign in** if you want it always on.
3. When setup finishes, Limitless Control opens its page in your web browser.

On a Mac, Limitless Control runs quietly in the background with no Dock icon. To open the
settings page again, open the app again from Applications or the Start menu.

## 3. Play

Open your music app. Limitless Control notices it and says its name, such as "Logic Pro".

| Switch | What it does |
|---|---|
| **A** (big left button) | Play / stop |
| **B** (big right button) | Tap: go to start. **Hold: record** (Ableton: hold to record) |
| X | Tap: undo. Hold: redo |
| Y | Loop or cycle on/off |
| D-pad up / down | Previous / next track (hold to keep moving) |
| D-pad left / right | Rewind / forward |
| LB / RB | Mute / solo (Ableton: track on/off, switch view) |
| LT / RT | Zoom out / in (hold to keep zooming) |
| **View** button | The next switch does its **layer 2** job (Save is on layer 2 of A) |
| **Menu** button | Tap: hear which app and layer you're on. **Hold: turn the controller off or on** |

Anything plugged into the 3.5 mm jacks on the back works like the button it's labelled with.

## 4. Make it yours

On the settings page:

- **Press any switch** and its row lights up. Choose what it does when you **tap** it, and
  something different when you **hold** it.
- Pick from named actions such as "Record" or "Show mixer", or choose **Custom key command**.
- **Timing:** if tremor or bumps set off switches, raise **Ignore presses shorter than**. If
  holds are hard, raise or lower **Hold time**.
- Switch spoken feedback on or off.

Changes save automatically and work straight away.

## Shortcuts to check

These depend on your DAW settings. If one doesn't work, choose the right key command on the
settings page.

- **Pro Tools:** rewind, fast forward and click use the number keypad (1, 2, 7). In
  Preferences > Operation, set Numeric Keypad to **Classic** or **Transport**. On Windows,
  previous/next track uses Start+P and Start+; which Windows may intercept. Pick different
  keys if they don't work.
- **Logic Pro:** mute and solo use Control+M and Control+S.
- **Ableton Live:** record uses F9. On Mac laptops, F9 may need the fn key or the
  "Use F1, F2, etc. keys as standard function keys" setting.

## Help

- **Nothing happens when I press a switch:** check the Status box on the settings page. It
  should name your controller. If it says **None connected**, reconnect by USB.
- **The page says the app isn't running:** open Limitless Control again.
- **Everything is too fast or too slow:** adjust the sliders under **Timing and feedback**.
