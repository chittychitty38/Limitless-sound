Getting this into Logic Pro and Pro Tools

Today, built in

macOS Settings › Accessibility › Display › Color Filters has fixed red-green and blue-yellow filters with an intensity slider. Logic's track color palette and the Pro Tools Color Palette window let you recolor tracks by hand. Use this page to find the colors that work, then type them in.

Next, a Mac screen filter

A small menu bar app captures the screen with ScreenCaptureKit, runs every frame through your .cube profile on the GPU, and shows it in a click-through overlay. It works on any app, including plugins and virtual instruments, with about one frame of delay.

Then, talk to it live

The same assistant runs inside the Mac app. You look at your real session, say "the solo button still looks like mute", and the overlay updates while you work. It pairs with the voice control work in this project.

How it works

Screen colors

Switch them on and your profile is applied to the whole screen: Logic Pro, Pro Tools, plugins and everything else. Closing this window keeps them on. Use the menu bar or tray icon to switch them off or quit.

Quick switch

Talk instead of typing

Press Talk, then speak. It uses your computer's own dictation, so any microphone that works with your computer works here.
