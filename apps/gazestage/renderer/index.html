Tone pad

Left–right makes the built-in sound darker or brighter, and up–down adds room, so you can hear the pad with nothing else connected.

For MIDI learn: start learning on the plugin or amp control, then choose Teach. Only that one controller moves, so it learns the right one.

Pro Tools and MIDI

GazeStage has its own MIDI ports, so there is nothing to install.

  1. In Pro Tools choose Setup › Peripherals › MIDI Controllers.
  2. Add a HUI with Receive From and Send To both set to GazeStage HUI.
  3. For instruments, set an instrument track's MIDI input to GazeStage Notes and record-enable it.
