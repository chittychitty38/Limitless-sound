# Limitless Sound website

The public page at https://chittychitty38.github.io/limitless-sound/ is `index.html` in this
folder, served by GitHub Pages (Settings > Pages > Deploy from a branch > `main` / `docs`).
It is plain HTML with no build step. Fonts are Atkinson Hyperlegible (SIL OFL, see `fonts/OFL.txt`).
